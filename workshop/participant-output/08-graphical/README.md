# graphical

Diagrams for current / interim / final state (Stage 08). Mermaid, so they stay
version-controlled text that renders in GitHub and in published artifacts — consistent with
the SDD principle that specs live alongside the code.

| View | File | Source of truth |
|---|---|---|
| Current state | [current_state.md](current_state.md) | `docs/product/state/current/` |
| Interim state | [interim_state.md](interim_state.md) | `docs/product/state/interim/` |
| Final state | [final_state.md](final_state.md) | `docs/product/state/final/`, `docs/architecture/c4/` |

These are **views**, not sources — if a diagram and its source document disagree, the
document wins and the diagram is the defect.
