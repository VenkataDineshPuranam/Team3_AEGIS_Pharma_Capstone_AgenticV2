# Prompt 02 — Evalability & Gap Analysis

```text
Using the repository reconnaissance, perform an EVALABILITY assessment.

Evaluate the following dimensions:

Correctness
Grounding
Authority
Safety
Security
Trajectory
Reliability
Human Oversight
Performance
Cost
Business Outcome

For each return:

- applicability:
  REQUIRED / CONDITIONAL / NOT_APPLICABLE

- workflow

- what must be measured

- evidence already observable

- evidence NOT observable

- existing tests that can be reused

- missing test capability

- appropriate grader

- likely gate type:
  HARD / THRESHOLD / ADVISORY

- whether the eval can run completely locally

Do not invent requirements.

Separate:

REPOSITORY REQUIREMENT

from

PROPOSED EVAL REQUIREMENT.

For missing business thresholds use:

THRESHOLD_NOT_DEFINED.

Create an Eval Coverage Matrix.

Do not modify files.
```
